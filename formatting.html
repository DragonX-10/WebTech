HTML Text Formatting

Formatting Tags

Bold text uses the b tag to draw attention to text.

Important text uses the strong tag to show importance.

Italic text uses the i tag for an alternate voice or a technical term.

Emphasized text uses the em tag to add stress.

Underlined text uses the u tag to mark an annotation.

Highlighted text uses the mark tag to show relevant text.

Small text uses the small tag for side notes.

Deleted text uses the del tag to show removed content.

Inserted text uses the ins tag to show added content.

Subscript uses the sub tag: H2O.

Superscript uses the sup tag: E = mc2.
